# 客製化

判斷規則全部是**中文寫的提示詞**，不用懂程式也改得動。改完記得 `python tools/build.py` 重新產生合併版，貼回 Apps Script，再重新部署。

---

## 改助理的名字

`00_Config.gs`：

```javascript
var 助理名稱 = 'LINE 小幫手';
```

會影響儀表板標題和雲端硬碟資料夾名稱。

> 改名字前如果已經有收藏資料夾了，舊資料夾不會自動改名。要換的話手動改，或把指令碼屬性裡的 `DRIVE_FOLDER_ID` 刪掉讓它重建。

## 改判斷規則

`02_Gemini.gs` 的 `問Gemini_`，那一大段中文就是給 Gemini 的指示：

```javascript
'判斷規則：',
'1. 只要提到「明確的時間點或會議、課程、活動、要去哪裡」→ 產生一個 calendar 動作。',
'2. 提到「要記得做、要處理、要交、待辦、提醒我」但沒有明確開始時間 → 產生一個 task 動作。',
'3. 只是隨口記事、心得、觀察、學生狀況 → 不用產生任何動作，只要摘要就好。',
```

想改脾氣就直接改這些句子。幾個實用的調整：

**想讓它更少建行程**（覺得它太雞婆）：

```javascript
'1. 要有明確的日期「和」時間才產生 calendar 動作，只講「下週」這種模糊時間就當記錄。',
```

**想加自己的慣用語**：

```javascript
'4. 使用者說「盯著」「追一下」都是要建待辦。',
'5. 提到「主任」「校長」的事情，category 一律歸 行政。',
```

**想改回覆語氣**：

```javascript
'- reply 用繁體中文、口語、親切，一到兩句話回應使用者。',
```

改成「簡短、不要客套，最多一句話」之類的。

同一段裡：

```javascript
'- category 從這幾個裡挑一個：教學、行政、學生、會議、個人、其他。',
```

改成適合你的分類。**同時要改儀表板的顏色表**（`Dashboard.html`）：

```javascript
var 色表 = {
  '教學': ['#e8f0fe', '#1a56c4'], '行政': ['#f3e8fd', '#6b21a8'],
  '學生': ['#e7f6ec', '#166534'], '會議': ['#fff2e8', '#c2410c'],
  '個人': ['#fde8f0', '#9d174d'], '其他': ['#eef0f3', '#4b5563']

```

沒列到的分類會用「其他」的灰色，不會壞掉。

## 換 Gemini 模型

`00_Config.gs`：

```javascript
var GEMINI_MODEL = 'gemini-3.5-flash-lite';
var GEMINI_MODEL_備援 = 'gemini-3.1-flash-lite';
```

不確定該填什麼就執行 **`檢查Gemini模型`**，會列出你的 key 能用的全部模型。

換之前建議跑 **`測試模型速度`**，它用真實任務比較各模型，同時看秒數和判斷正確性——**有些模型很快但拆不出行程和待辦，那種不能用**。

## 加新的快捷指令

`01_Webhook.gs` 裡有一段：

```javascript
if (輸入文字 && /^(今天|今日|行程|今天行程|早報)$/.test(輸入文字.trim())) {
  lineReply_(event.replyToken, 組出每日簡報_(new Date()));
  return;
}
```

照這個格式加就好。

> **不要設「開頭是某個字」這種寬鬆規則。** 本專案原本有個「查 XXX」的指令，結果使用者打「查到了嗎」就被誤判成要搜尋「到了嗎」。要嘛用完整比對（`^...$`），要嘛交給 Gemini 判斷意圖。

## 讓它回答新類型的問題

目前 Gemini 會判斷三種意圖：`記錄`、`問學校`、`問行程`。

要加第四種（例如「問進度」）：

1. `02_Gemini.gs` 的 schema 加進 enum：

```javascript
intent: { type: 'STRING', enum: ['記錄', '問學校', '問行程', '問進度'] },
```

2. 同一段的提示詞說明什麼情況算這種意圖
3. `01_Webhook.gs` 加對應的處理：

```javascript
if (結果.intent === '問進度') {
  lineReply_(event.replyToken, 你的回答函式());
  return;
}
```

需要根據資料回答的話，用 `問Gemini文字_(提示)` ——把資料和問題一起丟給它，回傳純文字答案。學校行事曆的 `回答學校行事曆_` 就是這樣做的，可以照抄。
