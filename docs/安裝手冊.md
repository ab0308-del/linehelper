# 安裝手冊

第一次安裝大約 30～40 分鐘。卡關的地方通常在 LINE 後台，不是程式。

建議照順序做，不要跳步驟。

---

## 第 1 步：申請 Gemini API Key

1. 開 <https://aistudio.google.com/apikey>
2. 按 **Create API key**，複製那串以 `AIza` 開頭的字
3. 免費額度日常使用綽綽有餘

> **卡關：出現「The request is suspicious」**
> 這是 Google 的防濫用機制誤判。改用無痕視窗、只登入一個 Google 帳號、關掉 VPN 和廣告封鎖擴充功能，再試一次。已經有其他 API key 的話直接拿來用也可以，同一支 key 能用在多個專案。

---

## 第 2 步：建立 LINE 官方帳號與 Messaging API

⚠️ **Channel 類型一定要是 Messaging API**，選成 LINE Login 就拿不到 access token，只能重建。

### 2-1 建立官方帳號

現在的 LINE 要先有官方帳號才能開 Messaging API：

1. 到 <https://manager.line.biz/> → **建立帳號**
2. 填名稱（這就是小幫手在 LINE 上顯示的名字）、電子郵件、公司或店家名稱、國家選台灣、業種隨便挑一個
3. 建立後會問要不要申請認證帳號 → 選 **「稍後進行認證（前往管理畫面）」**
4. 後面跳出的新手導覽（「增加好友人數」之類）直接關掉

> 認證帳號是給店家做行銷曝光用的，要送審要等，對個人助理完全沒用。

### 2-2 啟用 Messaging API

1. 管理畫面右上角 **設定**（視窗太窄的話按 `Ctrl` + `-` 縮小，它會被擠到畫面外）
2. 左側 **Messaging API** → **啟用 Messaging API**
3. 選擇服務提供者（Provider）→ 沒有就新建一個，名稱用學校名比較好管理
4. 隱私權政策與服務條款兩欄都是選填，**留空**直接下一步

> **Channel 建立後不能換 Provider**，要換只能重建，所以這裡挑定就別再改。

### 2-3 關掉自動回應

1. 左側 **回應設定**
2. **自動回應訊息** → **關閉** ← 這步最重要，不關的話你會收到罐頭訊息而不是小幫手的回覆
3. **聊天** → 關閉
4. **Webhook** → 現在還打不開是正常的（要等有網址才行），先跳過

### 2-4 拿 Channel access token

1. 到 <https://developers.line.biz/console/> → 你的 Provider → 剛建立的 Channel
2. 上方分頁點 **Messaging API**（不是 Basic settings）
3. **捲到頁面最底部** → **Channel access token (long-lived)** → 按 **Issue**
4. 複製那串（約 170 個字元）

> 本專案**用不到 Channel secret**。它是用來驗證簽章的，但 Apps Script 拿不到 HTTP 標頭，驗不了。

---

## 第 3 步：建立 Apps Script 專案

1. 開 <https://script.google.com/> → **新增專案**
2. 專案名稱改成「LINE 小幫手」
3. 左側齒輪 **專案設定** → 勾選 **「在編輯器中顯示 appsscript.json 資訊清單檔案」**
4. 回到編輯器，點 `appsscript.json` → 全選刪除 → 貼上本專案的 `appsscript.json` → 存檔
5. 點 `程式碼.gs` → 全選刪除 → 貼上 `dist/全部程式碼.gs` → 存檔
6. 左側 **檔案 +** → **HTML** → 檔名打 `Dashboard`（大小寫要對，不用打副檔名）→ 全選刪除 → 貼上 `src/Dashboard.html` → 存檔
7. 左側 **服務 +** → 找 **Tasks API** → 識別碼保持 `Tasks` → **新增**

---

## 第 4 步：填金鑰並初始化

1. `Ctrl + F` 搜尋 `初次設定`
2. 把第 1、2 步拿到的兩串貼進去（引號要留著，只換裡面的字）
3. 存檔
4. 上方函式選單選 **初次設定** → **執行**

**第一次會跳授權**，依序：

1. 「需要授權」→ **審查權限**
2. 選擇帳號 → 挑你平常在用的那個（日曆、待辦都會寫進這個帳號）
3. 出現「Google 尚未驗證這個應用程式」→ 點左下 **進階**
4. 點 **前往 LINE 小幫手（不安全）**
5. **允許**

> 這是自己寫的腳本，Google 對未驗證專案都會這樣提示，正常。
> 如果出現「這個應用程式遭到封鎖」而且沒有「進階」可點，代表是被學校 Workspace 管理員限制了，改用個人 Gmail 帳號。

執行成功後，執行紀錄會印出試算表網址，**加到書籤**。之後所有紀錄和錯誤訊息都在裡面。

**接著把程式碼裡的兩串金鑰刪掉、改回原本的提示文字並存檔。** 值已經寫進「指令碼屬性」了，留在程式碼裡不安全。

---

## 第 5 步：部署

1. 右上 **部署 → 新增部署作業**
2. 齒輪選 **網頁應用程式**
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人** ← 這欄不能選錯，LINE 是匿名打進來的
4. 按 **部署**，複製 `/exec` 結尾的網址

> ⚠️ 結尾一定要是 `/exec`，不是 `/dev`。`/dev` 只有你自己開得了。

---

## 第 6 步：把網址接回 LINE

1. LINE Developers Console → 你的 Channel → **Messaging API** 分頁
2. **Webhook URL** → **Edit** → 貼上 `/exec` 網址 → **Update**
3. 按 **Verify**（顯示 Success 最好；失敗但網址沒貼錯的話先往下測，Apps Script 會回 302 轉址，LINE 偶爾會誤判）
4. **Use webhook** 打開
5. 同一頁上方有 **QR code**，用手機掃描加為好友

---

## 第 7 步：測試

在 LINE 傳：

```
下週三下午兩點在會議室開領域會議，另外記得禮拜五前交研習報名表
```

正常會回「已記錄 / 已加入日曆 / 已加入待辦」三行。

再按住麥克風講一句話測語音，傳一張研習海報測圖片。

> 語音如果說格式不支援，把 `04_Line.gs` 裡的 `'audio/mp4'` 改成 `'audio/aac'`，重新部署。

---

## 第 8 步：打開儀表板

儀表板的網址就是你的 `/exec` 網址後面接上金鑰。三種取得方式：

**最簡單**：在 LINE 打「儀表板」，小幫手會直接回你完整網址（手機上長按就能複製）。

**或**：執行 **顯示儀表板網址**，它會印到執行紀錄並推一則到你的 LINE。

> ⚠️ **在編輯器執行時，Apps Script 只拿得到 `/dev` 開發網址**，那個只有你本人登入時打得開，手機上會失敗。
> 程式會偵測到並擋下來提醒你。而且 `/dev` 與 `/exec` 的 ID 不同，**不能手動把 dev 改成 exec**。

**或**：從「部署 → 管理部署作業」複製「網頁應用程式」那一行的網址（**不是**「部署作業 ID」），自己接上 `?k=金鑰`。

完整網址長這樣：

```
https://script.google.com/macros/s/AKfycb..../exec?k=a1b2c3d4e5f6g7h8
```

**手機上建議直接「加到主畫面」**（Safari 分享 → 加入主畫面），開起來就像一個 App。

> 從 LINE 的圖文選單點進去常常打不開——Apps Script 的 `/exec` 會先 302 轉址，
> LINE 內建瀏覽器常跟不上。**主畫面捷徑是最穩的做法**。

`?k=` 那串是門鎖。沒帶金鑰的話這個網址只會回一行狀態文字，看不到任何資料——因為 LINE 需要「所有人可存取」，這道鎖是必要的。

## 選用：教學模組

有固定課表的老師才需要。

1. 函式選單選 **建立課表** → 執行（會建立「課表」和「教學進度」兩個分頁）
2. 打開試算表的 **課表** 分頁，把範例改成你自己的課表
   - 星期欄：1=週一，5=週五
   - 一節課一列
3. 想讓教學行程進專用日曆的話：
   - 先在 Google 日曆建一個新日曆（例如「教學日曆」）
   - `Ctrl + F` 找 `設定教學日曆`，把 **日曆名稱** 填進 `日曆名稱`（不用找那串很長的 ID）
   - 存檔後執行該函式；名稱要一字不差，不確定就先執行 **列出我的日曆** 看看
4. `00_Config.gs` 的 `教學科目` 改成你教的科目

之後說「三年二班明天要做蒸發實驗」會進教學日曆，說「明天要去看牙醫」會進個人日曆。

## 選用：學校行事曆模組

```bash
pip install pymupdf
python tools/parse_calendar_pdf.py 你們學校的行事曆.pdf -o 學校行事曆.csv
```

1. 打開試算表 → **檔案 → 匯入 → 上傳** → 選產生的 CSV
2. 匯入位置：**插入新的工作表**
3. 分隔符號：**逗號**
4. **「將文字轉換成數字、日期和公式」不要勾**（避免「9/11」之類的內容被轉成日期）
5. 匯入後把分頁**改名為 `學校行事曆`**
6. 執行 **檢查學校行事曆** 對一次紙本

之後就能問「期中考什麼時候」「下週學校有什麼事」。

---

## 最後：確認每日推播

排程在 `初次設定` 時就建好了。左側 **觸發條件** 可以看到 `每日推播`。

想先看內容長怎樣，執行 **測試每日推播**（只印出來，不會真的傳）。

> 推播需要知道你的 userId，程式會在你第一次傳訊息時自動記住。所以務必先在 LINE 傳過至少一則訊息。

---

## 之後要改東西

改完程式碼一定要重新部署：

**部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署**

⚠️ 不要按「新增部署作業」，那會產生新網址，你得回 LINE 重貼。
⚠️ 版本下拉選單一定要改成「新版本」，只按部署等於沒改。這是最多人卡住的地方。

## 選用：LINE 圖文選單

把常用功能做成聊天室下方的六格選單，不用每次打字。

先產生底圖：

```bash
pip install pillow
python tools/make_richmenu.py
```

會在當下目錄產生 `圖文選單.png`（2500×1686，LINE 六格版型的尺寸）。
想改文字或配色，改腳本最上面的 `CELLS` 六行再跑一次就好。

接著到 <https://manager.line.biz/> → **圖文選單** → **建立**：

- 版型選 **6 格大型**（3×2），背景圖上傳剛產生的 PNG
- 選單列顯示文字隨便填，預設顯示選「顯示」

每一格的動作：

| 格子 | 類型 | 內容 |
|---|---|---|
| 學校行事曆 | 文字 | `學校` |
| 我的日曆 | 連結 | `https://calendar.google.com/` |
| 儀表板 | 文字 | `儀表板` |
| 試算表 | 連結 | 你的試算表網址 |
| 今天行程 | 文字 | `今天` |
| 收藏資料夾 | 連結 | 你的雲端硬碟收藏資料夾網址 |

> 「文字」類型的意思是「按下去等於幫你打這幾個字送出」，上限 50 字，不能放網址。

**儀表板那格建議用文字而不是連結**：一來以後重新部署換了網址不用改選單，
二來 LINE 內建瀏覽器本來就常開不起 Apps Script 的頁面（見疾難排解）。
